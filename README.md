# 💻 IT English Vocabulary Trainer (5000+ Words)

Інтерактивний хмарний тренажер для вивчення професійного IT-лексикону, побудований на Python та Streamlit.

## 🚀 Основні можливості
* 🎴 **250 комплексних карток:** Загалом понад 5000 IT-термінів, контекстні приклади та переклади.
* 🗣️ **Аудіоозвучення (EN):** Окремі кнопки для прослуховування чистої вимови термінів та прикладів (без номерів і завад).
* 🇺🇦 **Українська транскрипція:** Адаптивна фонетична вимова для кожного слова.
* 🎯 **Інтерактивний Квіз:** Режим перевірки знань із випадковими запитаннями.
* ⚡ **Оптимізована БД:** Миттєвий пошук та пагінація на базі SQLite.

## 🛠️ Технології
* **Python 3.10+**
* **Streamlit** (UI framework)
* **SQLite3** (Database)
* **gTTS** (Google Text-to-Speech)
